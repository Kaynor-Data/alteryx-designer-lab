# Alteryx Designer Lab

Laboratoire personnel d'apprentissage et de mise en pratique d'**Alteryx Designer** dans un environnement virtualisé VMware Workstation.

L'objectif est de maîtriser les fonctionnalités d'Alteryx pour la préparation, la transformation, l'analyse et l'automatisation des traitements de données.

## Objectifs du laboratoire

- Installer et configurer Alteryx Designer.
- Comprendre l'environnement de travail et les outils disponibles.
- Maîtriser les opérations ETL (Extract, Transform, Load).
- Importer et préparer des données hétérogènes.
- Nettoyer, filtrer, fusionner et agréger des jeux de données.
- Connecter Alteryx à une base de données PostgreSQL.
- Construire et automatiser des workflows.
- Réaliser des projets pratiques orientés Data Analytics et Data Engineering.

## Architecture technique

| Composant | Configuration |
|---|---|
| Hyperviseur | VMware Workstation |
| Machine virtuelle | Alteryx-Lab |
| Système d'exploitation | Windows 11 64 bits |
| Processeur | 4 vCPU |
| Mémoire RAM | 12 Go |
| Stockage virtuel | 500 Go (provisionnement dynamique) |
| Réseau | NAT (VMnet8) |
| Application | Alteryx Designer |
